## ✨ Key Features

### 1. 🎬 Continuous Viral Reels & Clips Marquee
- Horizontal auto-scrolling 9:16 vertical video showcase with pause-on-hover and manual navigation controls.
- Dynamic view badges (`+3.1k views`, `+7.5k views`, `+18.4k views`), kinetic caption overlays, and creator channel info.
- Interactive modal preview with playback simulation, live word-by-word captions, retention metrics, and one-click template loading.

### 2. ⚡ AI Studio & Social Matrix
- Multi-platform content generator for **Instagram, TikTok, X (Twitter), and LinkedIn**.
- Calibrated 3-second viral retention hooks, hashtag suggestions, and carousel slide outlines.
- Instant 1-click copy, save to library, and calendar scheduler.

### 3. 🎯 Viral Content Diagnostic Tool
- Live AI content analyzer evaluating clarity, engagement trigger, hook strength, and overall viral score (0–100).
- Actionable suggestions to improve retention before publishing.

### 4. 📅 Integrated Content Calendar & Workspace
- Unified scheduling calendar with drag-and-drop support.
- Media library for organizing drafts, published posts, and brand assets.
- Analytics dashboard tracking reach velocity, audience retention, and campaign ROI.

### 5. 🔐 Zero-Friction Authentication & Demo Access
- Clean navigation with matching **Get Started** button.
- Segmented **Create Account / Log In** switcher with instant 1-click Demo credentials (`Alex Rivera - Owner` / `Jordan Blake - Customer`).

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/maheshtalmale435-create/contentpilotai.git

# Navigate into the project
cd contentpilotai

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5174](http://localhost:5174) in your browser.

### Building for Production

```bash
npm run build
```

The production output will be generated in `dist/`.
